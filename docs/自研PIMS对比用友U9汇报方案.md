# 自研 PIMS 与用友 U9 对比方案

> 汇报人：王新宇 ｜ 2026-08

## 一、核心结论

| # | 结论 |
|---|---|
| 前提 | 公司独立运营要求与股东原属企业**完全隔离**（治理/财务/信息系统），共用 U9 不合规；单独再买 = 全额重复投入、零协同 |
| 事实 | 自研 PIMS **两个月上线 40+ 模块、6.8 万行代码**，业务需求**当天响应** |
| 成本 | 五年综合成本**不到 U9 的十分之一**（约 300 万元量级价值 vs 一名员工兼岗投入） |
| 建议 | 继续自研主线；数据结构标准化，保留将来规模化迁移路径 |

## 二、PIMS 现状（事实，非规划）

| 维度 | 现状 |
|---|---|
| 业务覆盖 | 生产/配方/质检/采购/委外/库存/销售/财务（含总账+三大报表）/工资/固定资产/CRM/打样/投诉/协同办公，**40+ 模块、76 个功能页** |
| 代码规模 | **430 个源码文件、68,100 余行**（后端 315 文件 3.9 万行 + 前端 115 文件 2.9 万行），≈5~8 人团队半年~一年工作量，代码资产**百万量级** |
| 数据规模 | 50+ 张业务表；物料/批次/库位三级库存精度；全链路批次追溯 |
| 迭代速度 | 两个月 **39 个版本**；单日可上线一个大模块（8/24 一天上线凭证+总账+三大报表） |
| 可靠性 | 每日 04:30 自动热备（90 天保留）+ 每周异地拉取；操作日志全留痕；崩溃自动重启；每版 26~30 项回归测试 |
| 使用成本 | 员工零培训、无专职 IT 运维、浏览器直接访问 |

## 三、与 U9 核心对比

| 对比项 | 用友 U9 | 自研 PIMS |
|---|---|---|
| **系统独立性（前提）** | 共用不符合独立运营要求且留关联痕迹；单买则重复投入零协同 | **完全独立开发/部署/数据，天然满足独立性** |
| 软件许可费 | 中型制造全套数十万起 | **0** |
| 实施费 | 约为许可费 1~2 倍 | **0** |
| 年维保费 | 约许可费 15~20%/年 | **0** |
| 数据库/中间件 | SQL Server / Oracle 另付费 | 免费开源、单文件库 |
| 实施周期 | 6~12 个月起 | **已上线运行**，需求按天交付 |
| 需求变更 | 提交厂商排期，2000~3000 元/人天 | **当天提出、当天/次日上线** |
| 行业贴合度 | 通用离散制造，行业特性需二次开发 | **按本厂业务口径逐条实现** |
| 员工上手 | 需分角色培训 | 零培训、大白话界面 |
| 数据归属 | 格式受制于厂商 | 单文件库，随时拷走可迁移 |

**五年总拥有成本**

| 方案 | 构成 | 量级 |
|---|---|---|
| U9 | 许可 50 万 + 实施 50 万 + 维保 5 年 50 万 + 定制 20 万 | **≈170 万元** |
| PIMS | 1 台服务器（万元级）+ 现有人员 | **≈1 万元级** |

> **真实案例印证**：股东原属企业当年上线 U9 实际投入 **200 余万元**，且**未含质检模块**——制造企业最核心的质量管控仍需另付定制。印证上述估算偏保守。

## 四、U9 标准版没有或需高价定制的行业能力（关键部分）

| # | 领域 | PIMS 已实现 | U9 现状 |
|---|---|---|---|
| 1 | 涂料配方体系 | 多版本管理、按批量折算、配方×工艺强制绑定、名称全厂唯一；**原料价一动理论成本即时联动，实时报价不再手算** | 通用 BOM，无配方版本+成本联动+±20% 预警逻辑，需定制 |
| 2 | 浆=半成品/漆=成品口径 | 一釜浆分装多成品、半成品/成品三维分类（主材/色系/光泽）、转生产自动识别 | 标准成本体系按此口径配置极绕，顾问按人天收费 |
| 3 | 全链路批次追溯 | 原料批号→到货→质检→投料→成品批→出库→客户**双向反查**；投诉一键追溯（含归档）；半成品多级溯源到浆批 | 需开批次管理模块+定制报表；客户验厂刚需 |
| 4 | 质检行业化 | 7 套物料大类检测模板、逐项实测+自动判定、**模板快照**（改模板不影响历史单）；不合格自动隔离、过期自动隔离+复检放行 | **质检模块缺失或另购**（股东企业 200 万上线即未含） |
| 5 | 质检信息随物料流转 | 质检结论**直接写入批次台账**（单号/判定/检验员/日期），库存视图、追溯链、索赔取证自动带出，零人工对照 | 即便补质检模块，质检与库存批次仍是两张皮 |
| 6 | 供应商质量追溯+索赔函 | 按批号一键带出采购链，自动生成四段式损失沟通函（多模板），强制填写处理结果 | 无对应功能 |
| 7 | 油尾退回与消化 | 剩浆/油尾退回入库、聚酯/氟碳分库；**生产领料自动消化油尾库存**（定向放行），退回-暂存-消化闭环 | 行业特有，无此概念 |
| 8 | 开单自动算投料 | 生产订单按**配方版本×批量自动折算**投料量与理论成本，领料参照执行，配方必选绑定防错料 | 需 BOM+MRP 模块配置并跑运算 |
| 9 | 领料差异三通道 | **先领料出库、事前管控、账实同步**；差异走退料/补领/作废三通道，成本与投出比自动联动 | 领料单**事后补做**，账实脱节，差异无正规通道 |
| 10 | 领料差异反哺配方 | 实际净领料 vs 计划用量统计，偏差≥5% 自动预警修订；上线即发现蓝浆 6 单全部多领 +5.1% | 无此能力 |
| 11 | 投出比与异常订单 | 入库合格自动完工、投出比自动计算、异常订单专项处理流 | 需定制报表+审批流开发 |
| 12 | 仓库隔离分库 | 每仓自动 5 个隔离分库（不合格×3+油尾×2）、库位级出入拦截、FIFO 自动分配 | 做不到该颗粒度的行业约束 |
| 13 | 业财一体（小厂口径） | 收款/付款/费用/发票/工资/折旧**一键生成凭证**，自动结转损益、期末结账、三大报表；与利润试算并存 | 财务强大但小厂嫌重，用不到集团合并 |
| 14 | 老板经营工具 | 经营看板、客户 360°、信用额度拦截、单据一键打印、**AI 智能助手**（自然语言查数）、菜单搜索 | 大 ERP 不会为你做 |
| 15 | 为工人设计 | 6 位编码数字全局连续（工人不会拿错料）、批号必选+FIFO 自动分配、按钮全系统统一样式 | 界面为办公室人员设计，车间用不起来 |
| 16 | 智能低库存预警 | 按物料×仓库统计用量，动态安全库存（日均×30 天），<15 天自动预警（<10 天红色）排序推送 | 需人工设定安全库存并手工核查 |
| 17 | 实时报表体系 | 20 余张报表全自研内置（经营/销售/采购/库存/生产/委外/质检/账龄/毛利/趋势/三大财务报表），**毫秒级响应**（实测中位 4~33ms） | 标准报表有限，分析需另购 BI 再定制 |
| 18 | 异常订单处理 | 投出比<95% 自动标记异常，专项跟进原因与处置（补料/报废/结案），异常不漂单 | 无对应功能，靠人工盯 |
| 19 | 工艺路线管理 | 多条命名路线、**配方必选绑定**、下单带默认路线、已引用禁删、打印贯通——防用错工艺 | 需制造模块深度配置，小厂用不起 |

## 五、U9 的优势与现阶段不需要的理由

| U9 优势 | 为什么现在不需要 |
|---|---|
| 多组织/集团财务合并 | 单体公司，无集团合并需求 |
| 数百人并发支撑 | 使用人数个位数到几十人，现有架构足够 |
| 成熟生态（PDA/条码/PLC） | 尚未到该阶段；需要时 PIMS 开放 API 可对接 |
| 上市合规审计背书 | 非上市、非公众公司 |
| 厂商长期支持 | 依赖单一开发人是真实风险，已用文档+AI+规范测试缓解（见第六节） |

> 将来多工厂/集团化时再评估大型 ERP；PIMS 为标准关系型数据，可完整迁移，**不构成锁定**。

## 六、自研风险与对策（已落地）

| 风险 | 对策 |
|---|---|
| 依赖单一开发人 | 全套文档（PRD 746 行/API/SOP 16 张流程图）、代码注释带版本号、AI 辅助降低门槛 |
| 质量事故 | 每版 26~30 项接口回归+浏览器验证；性能优化三批（索引/N+1/全表扫清零） |
| 数据丢失 | 每日自动热备 90 天+每周异地拉取+手动备份端点，恢复 SOP 已演练 |
| 误操作/舞弊 | 操作日志全留痕（按月分表）、字段级金额权限、10 角色权限矩阵 |
| 服务中断 | systemd 开机自启+崩溃自动重启，内网单点影响可控 |

## 九、结论与建议

| # | 结论/建议 |
|---|---|
| 1 | 不是"放着 U9 不用"，而是 **U9 买不回"贴合"**：60%+ 关键功能为行业定制，U9 路线 = 大额许可+更大额定制+漫长实施 |
| 2 | 投入产出已验证：两个月 39 版、40+ 模块、6.8 万行上线运行，需求当天响应 |
| 3 | 继续自研主线；下阶段按优先级补 MRP 缺料分析、扫码出入库、移动端查数 |
| 4 | **激励建议**：一名员工兼岗两个月交付约 300 万元量级价值且迭代零外包成本，建议按项目效益对核心人员给予专项奖励 |
