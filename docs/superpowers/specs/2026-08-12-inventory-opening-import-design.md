# 库存期初数据 Excel 导入设计

- **日期**：2026-08-12
- **状态**：已确认（用户逐段审批通过）
- **模块**：库存中心 → 期初数据导入

## 0. 设计原则

遵循系统总原则**标准化、流程化、准确性**：

- **准确性**：全量校验 + 单事务落库，要么全进要么全不进，绝不产生半套账；每行导入写 OPENING 异动流水，来源可追溯。
- **防重复**：已有库存的物料拒绝导入——同一份 Excel 二次导入会全部报错，天然防重，无需额外开关。
- **可用性**：期初库存记为合格（PASS），导入后立即可领用出库，不走质检流程（期初=线下已确认的库存）。

## 1. 背景与目标

系统上线（尤其后续正式服务器启用）时需要把线下实际库存一次性录入系统。当前库存只能靠采购/其他入库单据逐笔录入，无法批量初始化。

目标：库存中心提供「期初数据导入」，用 Excel 批量导入各物料的期初库存（每行一个批次），配套模板下载。

**使用场景**：一次性启用导入（用户确认），导入后系统靠单据自然流转。

## 2. Excel 模板

| 列 | 必填 | 说明 |
|---|---|---|
| 物料编码 | ✅ | 必须存在于物料档案且启用 |
| 物料名称 | 选填 | 仅供填报人阅读，系统以编码为准，不参与校验 |
| 仓库名称 | ✅ | 须与系统仓库档案名称完全一致 |
| 数量 | ✅ | >0；单位不需填写（台账 unit 与现有入库流程一致留空） |
| 单价 | 选填 | ≥0，用于计算库存金额 |
| 批号 | 选填 | 填了必须全局不重复；空则系统自动生成 |
| 生产日期 | 选填 | yyyy-MM-dd（兼容 Excel 日期单元格） |
| 过期日期 | 选填 | 空则按物料质保期从入库日推算（复用现有逻辑） |

模板下载为 xlsx：表头 + 2 行示例数据 + 表头批注填写说明。

## 3. 校验规则

上传后**先全量校验，任一行错误则整体拒绝**，一次返回所有错误（行号+原因），不写入任何数据：

1. 物料编码不存在或已停用 → 「第N行：物料编码 XXX 不存在/已停用」
2. 仓库名称与仓库档案不匹配 → 「第N行：仓库 XXX 不存在」
3. 数量 ≤0 → 「第N行：数量必须大于0」
4. 单价 <0 → 「第N行：单价不能为负」
5. **该物料台账已有库存（按 materialCode 合计 qty>0）→ 拒绝**（防重复导入核心闸门）
6. 批号已存在于数据库，或文件内批号重复 → 「第N行：批号 XXX 重复」
7. 日期格式无法解析 → 「第N行：生产日期/过期日期格式错误」
8. 文件为空/无有效数据行 → 整体拒绝

同一物料允许多行（多个批次），第 5 条只对照导入前的数据库状态。

## 4. 落库逻辑（单事务）

校验通过后在**一个事务**内写入：

### 4.1 台账（inventory_ledger，每行一个批次）

复用现有 `getOrCreateLedger` 模式：

| 字段 | 取值 |
|---|---|
| qty / availableQty | 导入数量 |
| unit / materialName | 物料档案带出 |
| unitPrice / amount | Excel 单价；amount = qty × unitPrice |
| batchNo | Excel 批号，空则 `generateBatchNo()` 自动生成 |
| inboundDate | 导入当天 |
| produceDate / expiryDate | Excel 值；过期日期空按物料质保期推算（复用采购入库逻辑） |
| qcStatus | PASS（期初即合格） |

### 4.2 异动流水（inventory_movement）

- 整批导入共用单号 `OPENING-{yyyyMMddHHmmss}`，便于按单号追溯整批导入
- 每行一条流水：`docType=OPENING`、方向 IN、qtyBefore=0、操作人=当前登录用户

## 5. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/inventory/opening/template` | 下载期初导入模板 xlsx |
| POST | `/api/inventory/opening/import` | MultipartFile 上传导入（全量校验+单事务落库） |

导入响应：成功 `{count: N}`；失败 `{code:400, msg:"导入失败", data:[{row:行号, reason:原因}...]}`。

权限：沿用库存写权限（与其他入库同级，实施时以现有权限码为准）。

## 6. 前端交互（Inventory.vue 工具栏）

工具栏现有「导出 Excel」旁新增两按钮：

- **下载期初模板**：直接下载后端生成的模板文件
- **导入期初数据**（el-upload，仅限 .xlsx/.xls）：
  - 选择文件后确认框：「期初导入将新增库存批次，校验失败不会写入任何数据，确定导入？」
  - 成功：提示「成功导入 N 个批次」，自动刷新库存列表
  - 失败：弹窗列出全部错误行（行号+原因），用户修改 Excel 后重新上传

## 7. 边界规则

| 场景 | 行为 |
|---|---|
| 同一文件二次导入 | 全部行因「已有库存」报错，天然防重 |
| 物料曾出库至 0（台账 qty=0） | 允许导入（判定依据是合计 qty>0，不是记录存在） |
| 导入中断/异常 | 事务回滚，无脏数据 |
| 批号与历史批次重复 | 校验拒绝（全局批号唯一是既有规则） |

## 8. 不在本次范围

- 期初导入的撤销/冲销（误导入靠「其他出库」调整）
- 周期性期初/盘点调整功能
- 库位（locationId）导入——期初默认不指定库位
