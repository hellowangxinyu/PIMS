# 侧边栏菜单搜索设计

- **日期**：2026-08-12
- **状态**：已确认（用户审批通过）
- **模块**：Layout.vue 侧边栏导航
- **范围**：仅前端，无后端改动

## 0. 背景与目标

侧边栏有 9 个分组、约 45 个菜单项，随着系统模块增多，找功能要靠人眼扫。目标：在侧边栏品牌区下方加搜索框，输入关键字**就地过滤**菜单，回车直达。

用户确认：**只搜菜单功能，不搜业务数据**；采用就地过滤交互（方案 A）。

## 1. 界面

```
┌─────────────────────┐
│  PIMS 进销存管理系统   │  ← 品牌区（不动）
├─────────────────────┤
│  🔍 搜索菜单（回车跳转）│  ← 新增搜索框，带 ✕ 清空按钮
├─────────────────────┤
│  工作台               │  ← 输入关键字时只显示匹配项
│  ▾ 基础数据            │     清空后恢复原样
│    …                  │
└─────────────────────┘
```

搜索框样式适配深色侧边栏（半透明白底、白色文字、圆角）。

## 2. 交互规则

| 场景 | 行为 |
|---|---|
| 输入关键字 | 菜单就地过滤：菜单名**或分组名**包含关键字（trim、忽略大小写）即显示；所在分组自动展开（无视折叠状态） |
| 回车 | 跳转第一个匹配项并清空搜索 |
| Esc / 点击 ✕ | 清空搜索，恢复原状（含分组折叠状态） |
| 无匹配 | 导航区显示"无匹配菜单"空提示 |
| 权限 | 沿用现有 hasPerm 条件，无权限的菜单不出现也不参与搜索 |
| 点击匹配项 | 正常跳转并清空搜索 |

## 3. 实现方式

**把模板中硬编码的菜单项抽成数据驱动**：

```js
// NAV_GROUPS: [{ key, title, icon, permAny: [..], items: [{ path, title, icon, perm }] }]
```

- 模板 `v-for` 渲染分组与菜单项（替代现有 45 行硬编码 router-link）
- 分组折叠状态（isGroupCollapsed/toggleGroup）逻辑保留
- 搜索过滤在该数据上完成：
  - `searching = keyword.trim() !== ''`
  - 组内匹配 = 组名包含 或 任一菜单名包含；菜单匹配 = 菜单名包含
  - 搜索中：所有组强制展开；否则按折叠状态
- 顶部"工作台"项与底部用户区不动
- 移动端（侧边栏抽屉）同样生效，无需额外处理

**注意**：抽取数据时菜单名称/路径/权限条件必须与现状**逐一对应**，不允许顺手改名（如 pageTitle map 保持独立不动）。
