## 全局操作规则

1. **质检前置**：所有入库（采购/生产/委外/其他）均需质检合格方可入库，库存即合格品；出库不再校验质检
2. **批次必选**：所有出库（生产/委外/销售/其他）必须选择批号，实际成本按批号单价直取
3. **三级仓位**：所有出入库操作需选择 仓库 → 分库 → 库位 三级，下级依赖上级联动
4. **财务联动**：货到/发货才产生应付/应收，下单时不产生；内部成本流转（生产领料/入库）不产生 AR/AP
5. **权限控制**：写操作按钮按角色权限显隐，admin 账号拥有全部权限
6. **状态中文化**：所有状态字段均显示中文，出现英文请联系管理员重新打包
7. **单位统一（v1.5）**：所有物料单位统一为公斤（kg），生产/委外/配方单据单位不可修改

## 一、基础数据维护

> 使用角色：管理员（SS）、总经理（GM）
> 前置条件：系统初始化完成，已用 admin/admin123 登录

### 1.1 物料管理

**路径**：基础数据 → 物料管理

**新增物料**：
1. 点击「新增物料」按钮
2. 选择「大类」（A=助剂/P=颜料/F=填料/R=树脂/S=溶剂/B=半成品/C=成品）
3. 选择「小类」（联动，如选成品大类则显示底漆/清漆/面漆等小类）
4. 点击「生成编码」按钮自动生成物料编码（格式：小类代码+数字+3位序号，如 AC40001）
5. 填写品名、牌号、质保期(天)（0 或空表示不限）
6. **品牌归属（v4.5 新增，仅成品C）**：当大类选择 C(成品) 时显示「品牌归属」字段
   - 自产成品：直接输入「芃远」（默认值）
   - 外购成品：可从下拉选择成品供应商，选中后自动填入供应商名称
7. 点击「保存」

**查重规则**：物料按「品名+牌号+大类+小类」完全一致查重，重复录入会报错

**平替物料配置（v1.8，仅原材料，双向关系）**：
1. 在原材料（大类 A/P/F/R/S）列表行点击「编辑」
2. 在「平替物料」下拉中选择可完美替代该物料的原材料（可多选，仅显示其他原材料）
3. 保存后**自动建立双向关系**：对方物料的平替列表也会自动包含本物料（取消配置时自动反向移除）
4. 配方管理 → 配方树编辑时，配置了平替的原料节点会出现「⇄平替」按钮，点击可一键切换为平替物料，**可在平替物料之间来回切换**（用量保持不变，可按需调整）

**编辑/删除**：列表行内点击「编辑」或「删除」（删除需二次确认）

**搜索筛选**：顶部大类标签筛选 + 编码/品名模糊搜索

### 1.2 客户管理

**路径**：基础数据 → 客户管理

**新增客户**：
1. 点击「新增客户」
2. 填写名称（同名客户不允许重复）、联系人、电话、地址
3. 选择等级（A/B/C）
4. 选择收款条件（款到发货/账期30天/账期60天/月结/两月结/三月结/自定义账期）
   - 选「自定义账期」需填写天数（1-365 天）
5. 选择收款方式（电汇/承兑）
6. 点击「保存」

**业务影响**：收款条件决定应收账款的到期日（款到发货=发货当天；账期N天=发货日+N天；月结=次月1号；两月结=+2月1号；三月结=+3月1号）

### 1.3 供应商管理

**路径**：基础数据 → 供应商管理

**新增供应商**：
1. 点击「新增供应商」
2. 填写名称
3. 选择类型（材料供应商 MATERIAL / 成品供应商 FINISHED）
   - 材料供应商：仅可被原料采购单引用
   - 成品供应商：仅可被成品采购单引用
4. 选择付款条件、付款方式（需 `supplier:payment` 权限，仅 GM 与 FINANCE 角色可见）
5. 点击「保存」

---

### 1.4 仓库管理

**路径**：基础数据 → 仓库管理

**三级结构**：仓库 → 分库 → 库位

**新增仓库**：
1. 点击「新增仓库」
2. 填写编码（自动生成）、名称、类型（自有原料仓/委外原料仓/自有成品仓/委外成品仓）、所属工厂、地址等
3. 点击「保存」

**新增分库**：在仓库列表选中某仓库 → 右侧「分库管理」面板 → 「新增分库」（编码自动生成 Z+3位序号）

**新增库位**：在分库列表选中某分库 → 右侧「库位管理」面板 → 「新增库位」（编码自动生成 L+3位序号）

## 二、配方管理

> 使用角色：技术主管（TECH_LEAD）、技术员（TECHNICIAN）

### 2.1 新建配方

**路径**：配方管理

1. 点击左侧配方列表上方「新建配方」
2. 选择配方类型（制浆 GRINDING / 制漆 TINTING）
3. 填写配方编号、品名、产品编码、分类、描述
4. 点击「保存」

### 2.2 新建版本与编辑配方树

1. 在左侧列表选中配方 → 右侧详情面板「版本」区域 → 「新建版本」
2. 填写版本号、标准批量（固定 100kg）、单位
3. 版本状态为「草稿(DRAFT)」时，配方树区域可编辑：
   - 点击「+ 添加节点」添加原料
   - 点击「+ 添加子节点(半成品)」引用其他配方的子配方
   - 填写每个节点的用量
   - 点击「保存树」
4. **校验**：根节点物料用量之和必须等于标准批量（误差 ≤ 0.001），否则无法保存

### 2.3 平替物料一键切换（v1.8）

**前置**：物料管理中已为原材料配置平替物料（见 1.1）

1. 配方树编辑状态（版本为草稿）下，原料节点行出现「⇄平替」按钮
2. 点击「⇄平替」→ 弹窗列出该物料的平替物料（编码/品名/牌号/分类）
3. 点击「切换」→ 节点物料替换为平替物料，**用量保持不变**（可按需调整）
4. 点击「保存树」生效（成本自动按新物料重算）

### 2.4 发布版本
1. 在版本表中对草稿版本点击「发布」按钮
2. 该版本状态变为「已发布(RELEASED)」
3. 同一配方的旧 RELEASED 版本自动转为「已归档(ARCHIVED)」
4. **只有已发布版本的配方才能被生产订单/委外订单引用**

### 2.5 禁用/启用配方

**路径**：配方管理 → 左侧列表选中配方 → 右侧详情面板顶部

- **禁用**：点击「禁用」按钮 → 二次确认 → 配方状态变为「停用」
  - 禁用后该配方不可被任何生产订单、委外订单引用
- **启用**：点击「启用」按钮 → 配方恢复为「启用」状态

**查看禁用配方**：列表顶部切换「启用中」「已禁用」Tab 筛选

### 2.6 配方打印（保密版）

1. 选中配方 → 点击「打印」按钮
2. 浏览器新窗口打开 A4 排版配方单
3. **保密规则（v1.7）**：原料不显示品名、不显示单价/成本，仅保留物料编码（工人按编码找料）；**半成品显示名称（加粗），其子配方明细展开缩进展示**，层级结构一目了然
4. 使用浏览器原生打印（Ctrl+P）

## 三、采购管理

> 使用角色：采购员（BUYER）

### 3.1 采购下单

**路径**：采购管理 → 原料采购 / 成品采购

1. 点击「新增采购」
2. 选择采购日期
3. 选择供应商（原料采购仅显示材料供应商，成品采购仅显示成品供应商）
4. **添加物料明细（v1.6，一单多物料）**：点击「+ 添加物料」逐行添加，同一张单据（同一合同号）支持多个物料：
   - **原料采购（v4.5）**：物料下拉仅显示大类 A/P/F/R/S（助剂/颜料/填料/树脂/溶剂），不含半成品(B)和成品(C)；选择物料自动回填上次采购单价
   - **成品采购（v4.5）**：物料下拉仅显示大类 C（成品），每项旁边有「成品」绿色标签；物料列表按供应商品牌归属自动过滤，选择后自动带出牌号
5. 填写每行数量、单价（勾选「赠送」时单价强制为 0），系统自动计算金额与合计
6. 可上传采购合同（PDF 文件，编辑草稿时）
7. 点击「保存」→ 整单生成草稿(DRAFT)，同一合同号下多行明细
   - **成品采购品牌归属校验（v4.5）**：保存时后端校验供应商名称必须等于物料品牌归属(brandOwner)，不一致报错「供应商与物料品牌归属不一致」
   - **编辑草稿（v1.6）**：列表行内「编辑」为单行编辑，仅修改该行明细

### 3.2 采购审核

1. 在「开立单据」Tab 找到草稿单据
2. 点击「审核」按钮 → 状态变为「已审核(APPROVED)」
3. **反审核**：在「历史单据」Tab 对已审核单据点击「反审核」可撤回（需 `purchase:reverse-audit` 权限）

### 3.3 到货录入

**路径**：采购管理 → 采购到货

1. 选择「原料到货」或「成品到货」Tab
2. 列表仅显示未完全到货的已审核订单
3. 对目标订单点击「录入到货」
4. 填写本次到货数量（不超过未到货量）
5. 选择入库仓库 → 分库 → 库位
6. 点击「确认」
   - 部分到货：订单保持「已审核」
   - 全部到货：订单自动转为「已到货(RECEIVED)」
7. **结束订单**：未到货但不再补货的订单可点击「结束订单」转为「已关闭(CLOSED)」

### 3.4 质检与入库（自动）

1. 到货录入后，系统自动生成来料质检单（待检状态）
2. 跳转至「质检管理」进行 QC 判定（详见 第八章）
3. **质检合格**：系统自动入库，库存增加，自动生成应付账款(AP)
4. **质检退货**：系统自动生成采购退货单（详见 3.6）

### 3.5 到货明细查询（v1.9）

**路径**：采购管理 → 采购到货 → 「到货明细」Tab

1. 顶部切换到「到货明细」Tab
2. 选择「原材料明细」或「成品明细」子 Tab
3. 列表展示每次到货记录：到货日期、合同号、供应商、物料、到货数量、仓库/分库/库位、操作人
4. 超过 50 条自动分页（50/100/200 可切换）

> 到货明细由「录入到货」操作自动产生（含质检待检前的到货记录），无需手工维护

### 3.6 采购退货流程

**路径**：采购管理 → 采购退货单

1. **自动触发**：QC 判定「退货(REJECT)」时系统自动生成退货单（草稿状态）；该批货物**不进入仓库、不生成应付**
2. **采购员审核**：对草稿单据点击「审核通过」或「驳回」（驳回需填原因）
3. **退货完成**：审核通过即退货完成——货物直接退回供应商（无出库操作、无库存变动），**不冲减应付账款**（退货部分从未立账）
4. **已退货明细**：页面「已退货明细」Tab 展示所有已完成的退货记录（含审核人/退货完成时间），超过 50 条自动分页

**状态流转**：草稿(DRAFT) → 已退货完成(DONE)
或：草稿(DRAFT) → 已驳回(REJECTED)

### 3.7 销售退货流程（v1.10）

**路径**：销售管理 → 销售退货

1. **创建退货单**：点击「新建退货单」→ 可先选择「参照销售出库单」自动带出客户/物料/单价，或手工选择客户、物料并填写数量（单价可手改）→ 提交
2. **销售员审核**：对草稿单据点击「审核通过」或「驳回」（驳回需填原因）
3. **仓管退货入库**：对已审核退货单点击「退货入库」→ 选择仓库/分库/库位 → 确认（批号自动生成）
4. **自动冲减应收**：入库确认时系统按原销售订单号 FIFO 红冲未结清应收账款，并回写销售订单明细退货数量
5. **已退货明细**：页面「已退货明细」Tab 展示所有已完成（已入库）的退货记录（含客户/原销售单号/入库单号/审核人/入库时间），超过 50 条自动分页

**状态流转**：草稿(DRAFT) → 已审核待入库(APPROVED) → 已入库完成(DONE)
或：草稿(DRAFT) → 已驳回(REJECTED)

## 四、生产管理

> 使用角色：生产管理员（PM）

### 4.1 生产订单

**路径**：生产管理 → 生产订单

**新建订单**：
1. 点击「新建生产订单」
2. 选择配方类型（制漆/制浆）
3. 选择参照配方（下拉仅显示已发布且启用的配方版本）
4. 填写产品名称、生产批量（不得低于 100kg）
5. 系统按比例自动计算投料量（实际投料量 = 配方用量 × 生产批量 ÷ 标准批量）
6. 点击「保存」→ 状态为「草稿(DRAFT)」

**列表 Tab 分组**：
- 「未完工」Tab（默认）：显示草稿 + 已确认订单，带数量徽标
- 「已完工」Tab：显示已完工订单，带数量徽标

**状态流转**：
1. 草稿(DRAFT) → 点击「确认」→ 已确认(CONFIRMED)
2. 已确认(CONFIRMED) → 完成生产后点击「完工」→ 已完工(COMPLETED)
3. 草稿(DRAFT) 可「删除」，已确认/已完工不可删

### 4.2 生产出库（领料）

**路径**：生产管理 → 生产出库

1. 点击「参照订单领料」
2. 选择生产订单（v1.2：下拉仅显示可出库订单，已完工/已出库/已入库完成的订单不显示）
3. 选择出库仓库
4. 配方明细表中，**每行物料必须选择批号**（下拉显示：批号 + 分库/库位 + 现存量，不显示价格）
5. 可调整「出库用量」（最小 0.001，精度 3 位）
6. 点击「确认」→ 单据自动确认并立即扣减库存

**实际成本**：按批号库存台账单价直取，落库 unit_price 与 cost

### 4.3 生产入库

**路径**：生产管理 → 生产入库

**前置校验**：必须先完成生产出库（领料），否则系统提示「该生产订单尚未进行生产出库，不允许参照生成生产入库单」

**操作步骤**：
1. 点击「参照订单入库」
2. 选择生产订单（v1.2：下拉仅显示可入库订单，必须已出库且无已完成/待质检的入库单，已完工订单不显示；系统校验存在已确认的生产出库单）
3. 填写入库数量（实际产出）
4. 选择入库仓库 → 分库 → 库位
5. 批号系统自动生成（B+日期+序号，如 B20260804-001）
6. 点击「保存」→ 状态为「草稿(DRAFT)」
7. 点击「确认」→ 状态变为「待质检(CONFIRMED)」→ 自动生成质检单
8. 跳转质检管理进行 QC 判定（详见 第八章）
9. **质检合格**：系统自动入库，状态回写为「已入库(DONE)」，库存增加
10. **质检退货**：状态回写为「质检退货(REJECTED)」

**得率记录**：系统自动计算 得率 = 实际产出 ÷ 理论产出(配方批量) × 100%
- 得率 ≥ 98% 绿色 / ≥ 90% 橙色 / < 90% 红色

**溯源**：行内点击「溯源」可查看配方谱系树 + 实际领料批次 + 采购来源

## 十二、典型业务流程串联

### 12.1 采购全流程

```
新增物料 → 新增供应商 → 原料采购下单(DRAFT) → 审核(APPROVED)
  → 到货录入(选仓库/库位) → 质检(待检)
    ├─ 合格 → 自动入库 + 生成应付 AP → 付款单(冲减 AP)
    └─ 退货 → 生成退货单(DRAFT) → 采购员审核通过 → 退货完成（货直接退回，不入库、不立应付、不冲减）
```

### 12.2 生产全流程

```
新建配方 → 编辑配方树 → 发布版本 → 新建生产订单(DRAFT) → 确认(CONFIRMED)
  → 生产出库/领料(选批号,扣库存) → 生产入库(前置校验:必须已出库)
    → 确认(待质检) → 质检合格 → 自动入库(状态 DONE)
  → 生产订单完工(COMPLETED)
  → 溯源查看(配方谱系+领料批次+采购来源)
```

### 12.3 委外全流程

```
新建委外订单(设代工厂+加工费) → 确认(CONFIRMED)
  → 委外出库/发料(选调出仓,直接扣库存,不再调拨到委外仓)
  → 委外入库/回库(前置校验:必须已委外出库) → 确认(待质检)
    → 质检合格 → 自动入库 + 生成加工费 AP(入库量×加工费单价)
  → 委外订单完工(COMPLETED)
```

### 12.4 销售全流程

```
新增客户 → 销售订单下单(DRAFT) → 确认(CONFIRMED)
  → 发货(选批号,生成草稿出库单,不扣库存)
  → 仓管审核确认(扣库存+生成应收 AR,按客户账期算到期日)
  → 全部发完订单自动置 SHIPPED
  → 收款单(选客户,FIFO 冲减 AR)
```

### 12.5 库存调整流程

```
盘盈: 盘库管理 → 选仓库/物料 → 填实盘(>系统) → 确认(增库存)
盘亏: 盘库管理 → 选仓库/物料 → 填实盘(<系统) → 确认(扣库存)
库位调整: 盘库管理 → 选仓库/物料/目标库位 → 确认(库位间转移)
```

## 十三、注意事项与常见问题

### 13.1 操作注意事项

1. **编码不可修改**：物料编码、仓库编码、分库编码、库位编码一旦生成不可修改
2. **配方用量校验**：保存配方树时根节点用量之和必须等于标准批量
3. **批号必选**：所有出库操作必须选择批号，否则提交报错
4. **生产入库前置校验**：未做生产出库的生产订单不允许生成生产入库单
5. **委外入库前置校验（v4.5）**：未做委外出库的委外订单不允许生成委外入库单
6. **委外出库（v4.5）**：仅需选择调出仓，直接扣减调出仓库存，不再调拨到委外仓
7. **销售发货两步确认**：发货仅生成草稿出库单，仓管审核确认后才扣库存和生成应收
8. **成品采购品牌归属校验（v4.5）**：供应商名称必须等于物料品牌归属(brandOwner)
9. **原料采购物料限制（v4.5）**：仅可选大类 A/P/F/R/S 的物料
10. **成品采购物料限制（v4.5）**：仅可选大类 C 的物料
11. **查重规则**：物料按品名+牌号+大类+小类查重，客户按名称查重，供应商按名称+类型查重，重复不允许录入
12. **参照订单过滤（v1.2）**：生产/委外出入库参照订单时，已完工订单（COMPLETED 状态、或已存在 DONE 入库单、或已存在 CONFIRMED 出库单）直接不显示在参照下拉列表中

### 13.2 数据异常处理

1. **库存页可用量红色高亮**：表示「可用量」与「库存量」不一致，属于历史脏数据，出库校验基于「库存量(qty)」不受影响
2. **状态显示英文**：联系管理员重新打包后端 jar 并强制刷新浏览器（Ctrl+F5）
3. **有库存却无法出库**：检查批号是否正确、仓库/库位是否匹配

### 13.3 系统维护

1. **前端发布新版本后**：用户需 Ctrl+F5 强制刷新浏览器缓存
2. **后端更新后**：需 `mvn clean package -DskipTests` 重新打包并重启服务
3. **数据库备份**：直接复制 `pims-server/data/pims.db`（建议停服复制）
4. **默认账号**：admin / admin123（角色 SS，全权限）
